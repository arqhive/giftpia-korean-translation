# 창 크기 표 (3단계, 2026-10-01)

측정: 시험 C(자 대기 빌드)를 돌핀에서 확인. 글자는 **고정폭**(측정 함수 0x8008EA44 가 글자마다 같은 폭을 더함)이라 글자 수로 잰다.

| 창 | 명령 | 한 줄 한도 | 권장 | 줄 수 | 근거 |
|---|---|---|---|---|---|
| 일반 대사 | 66 / 88 / 주소형 77·7F·89 | 28자(실측: 28자 전부 보임) | 20자(원문 99.5%) | 페이지당 3줄(4번째 줄은 위로 밀림) | 시험 C 스크린샷 |
| 선택지 | 7E (`{12}` 로 항목 구분) | 22자(실측) | 19자(원문 최대) | 항목 2~3개 | 시험 C 스크린샷 |
| 라디오 DJ 흐르는 자막 | 66, 화자 `{0C}{12}` | 제한 없음(가로로 흐름) | — | 1줄 | 원문 최대 140자 |

- 페이지 구분: `{01}`·`{02}`(버튼 대기). 줄바꿈: `0x0A`
- 글자 크기 코드 `{04}{xx}` 가 쓰인 대사(약 1,600곳)는 폭이 달라질 수 있음 → 4단계에서 표시해 두고 실행 검수 때 확인
- 끼워 넣기 폭 가정: `{10}`(숫자) 5자, `{11}`(아이템 이름 등) 12자
- 검사 도구: `tools/check_text.py` (error = 한도 초과, warn = 권장 초과)
- 미측정: 6D C8 주소형 텍스트(기록 표시 등 172곳)·메뉴(main.dol 문자열)·그림 글자 창 → 해당 번역 때 따로 확인
